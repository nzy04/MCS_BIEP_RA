# MCS_BIEP 首次上线：维护者最后配置

网站：https://mcs-biep-ra.zn77710.workers.dev

仓库：https://github.com/nzy04/MCS_BIEP_RA

代码、网站和单仓库安装已完成。登录与正式发布还需要下面两个服务端密钥；不要把密钥发到聊天或提交到 GitHub。

## 1. GitHub 登录密钥

打开 [应用 Credentials](https://github.com/settings/apps/mcs-biep-ra-nzy04/credentials)，在 Client secrets 中生成一个 Client secret。复制这个值。

回到 Cloudflare → Workers & Pages → mcs-biep-ra → Settings → **Runtime variables and secrets**，点击 Add variable：

- Type 选择 **Secret**。
- Name 填 `GITHUB_CLIENT_SECRET`。
- Value 粘贴刚生成的 Client secret。
- 保存并部署。

这里需要的是 Client secret；不需要生成或上传 Private key，也不是 GitHub 个人访问令牌。

## 2. 网站会话密钥

在同一处再添加一个 **Secret**，Name 为 `SESSION_SECRET`，Value 使用密码管理器生成的至少 32 字符随机值。

本机已准备了 `.setup-session-secret.txt`，可以复制该文件中的随机值。该文件被 Git 忽略，不会上传。密钥只在本机与 Cloudflare Secret 保存。

完成后刷新网站，点击 GitHub 登录。只有有本仓库写权限的成员可以发布；公开阅读无需登录。

## 配置后验收

登录 → 上传测试笔记 → 修改模板 → 发布 → 查看 GitHub 提交 → 刷新网站读取。正式发布前仍需要真实账号完成这一轮验收。

## 成员使用

维护者在仓库 Settings → Collaborators 中邀请组员。组员接受邀请后只需要网站登录、上传与确认发布，无需操作 Git 命令。

当前支持 DOCX、文字 PDF、MD、TXT；扫描 PDF 不支持 OCR，复杂公式、表格和 PDF 插图需要人工校对。
