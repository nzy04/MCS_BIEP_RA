# 图文笔记

打开网站 → 上传笔记 → 继续整理 → 查看发布预览 → 确认发布。审核进度和修改反馈在「我的提交」中查看。

## 导入

| 文件            | 操作                                                               |
| --------------- | ------------------------------------------------------------------ |
| Word（DOCX）    | 选择文件，导入正文、内嵌图片和表格。                               |
| Markdown + 图片 | 一次选择笔记及全部配套图片，按文件名绑定引用；同名图片需先重命名。 |
| ZIP 笔记包      | 压缩包中放一份笔记及其图片，可附一份论文 PDF。                     |
| PDF + 笔记      | 将笔记作为主文件，论文 PDF 放入「论文原文」；两者分别保存。        |
| PDF 笔记        | 可提取文字型 PDF 的文本，排版、图表和公式需人工核对。              |

正文保留原章节和顺序。「插入参考模板」只提供可选提纲，不会重排现有内容。观点、综述与方法论文可自行调整章节。

## 编辑与阅读

- 在正文中直接修改，工具栏可设置标题、列表、引用和表格；点击表格可添加行列、合并或拆分单元格。
- 「图片」在光标处插入图片和图注；也可粘贴剪贴板图片。
- 附上论文 PDF 后，「PDF 选页插图」可插入指定整页。只需要某张图时，可先截图再上传。
- 「Markdown」切换到源码编辑。普通表格保存为 Markdown；合并单元格表格使用 HTML 保留结构。
- 阅读页点击图片可查看原图。「导出笔记包」下载正文和附件，下载包可再次导入。

扫描 PDF 需要先 OCR；当前不自动识别 PDF 中的独立图表，也不保证公式和复杂 Word 版式无损转换。导入后请检查原文、图注和数值。

## 存储

| 路径                   | 内容                                               |
| ---------------------- | -------------------------------------------------- |
| `data/notes/<id>.json` | 元数据、完整 Markdown 正文、附件清单和审核记录。   |
| `papers/<id>.md`       | 可在 GitHub 直接阅读的版本，图片使用仓库相对路径。 |
| `assets/uploads/<id>/` | 该笔记的图片及论文 PDF。                           |
| `data/library.json`    | 网站检索索引，不包含完整正文。                     |

发布时同步保存正文、阅读版、索引与新增附件；编辑后移除的附件会从当前版本删除，历史仍由 Git 保存。请通过网站编辑，避免 JSON 与 Markdown 内容不一致。历史笔记继续兼容，无需迁移。

单张图片不超过 2 MB，论文 PDF 不超过 4 MB，发布附件总计不超过 6 MB。ZIP 不超过 15 MB，展开后不超过 30 MB，最多 80 个文件。原始大文件建议保留官方链接。
