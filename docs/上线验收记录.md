- GitHub App 公开注册，安装范围仅限 `nzy04/MCS_BIEP_RA`；权限为 Contents 读写与 Metadata 读取。

- 退出登录后可以公开阅读，未登录的发布请求返回 401。
- 代码重新部署后登录配置仍有效。

## 已通过的本地验证

- 10 项接口和核心逻辑测试，包括会话加密、未登录拒绝、跨站请求拒绝、权限与附件路径校验、原子提交、分支并发与旧版本冲突。
