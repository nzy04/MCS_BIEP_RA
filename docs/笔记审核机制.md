# 共享笔记审核

仅成员点击“确认发布到仓库”时提交审核。选文件、解析、编辑、预览和公开阅读均不调用模型。

1. 校验登录、仓库写权限、大小、重复提交和每日限额。
2. 按规则整理已有章节。明显空缺或过短的笔记直接反馈，避免花费模型额度。
3. 缺少论文来源或年份时，先用笔记中的 DOI / arXiv 编号及 Crossref 标题匹配查找。不能可靠定位时才使用一次 DeepSeek Search，限定学术来源与严格标题匹配。
4. 一次 DeepSeek JSON 审核判断是否包含研究问题、方法和本人理解，并从内容提炼 1–3 个研究方向，优先复用已有标签。模型只能提取原文已有的文字填入空章节。
5. 通过后自动提交 GitHub。未通过返回具体字段与修改建议。模型、检索或授权故障均保留任务及草稿，不绕过审核发布。

个人思考、实验数值、结论不会用搜索结果代写。自动补充的来源和字段保存在笔记的审核记录中，与原笔记区分。

审核在 SQLite Durable Object 的持久任务和 alarm 中执行。网页刷新或关闭不终止已提交任务。审核任务只对提交者可见；未通过内容不会出现在公开仓库。待处理的授权与上传内容加密保存，24 小时后清理；任务状态保留 7 天。

默认全组每日 50 次、每人每日 10 次提交；一次审核最多一次聊天请求、必要时一次搜索请求，输入正文上限 40,000 字符，输出上限 3,000 tokens。超时或进程中断不自动重复付费请求，成员可明确重试；已通过的提交重试发布时复用审核结果。

维护者只配置一次 Cloudflare Secret `DEEPSEEK_API_KEY`，不放在前端、GitHub 或成员表单里。默认模型 `deepseek-flash`，可用环境变量 `DEEPSEEK_MODEL` 调整。未配置密钥时停止仓库发布，公开阅读和本机编辑继续可用。

仓库维护者登录后可打开 `/api/reviews/connection` 检查密钥与模型连通性。该检查只读取模型清单，不执行论文分析，也不发布笔记。

实现依据：[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[DeepSeek Search](https://api-docs.deepseek.com/api/search/)、[Cloudflare Alarms](https://developers.cloudflare.com/durable-objects/api/alarms/)、[Durable Objects 免费额度](https://developers.cloudflare.com/durable-objects/platform/pricing/)。
