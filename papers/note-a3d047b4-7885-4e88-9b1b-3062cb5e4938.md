# MCS_BIEP 使用指南（上线验收）

## 一句话总结

这是一篇网站使用指南和上线验收记录，不对应研究论文。组员登录 GitHub 后可上传笔记、确认模板并发布到共同仓库。

## 方法与贡献

1. 点击“上传笔记”，选择 DOCX、文字型 PDF、Markdown 或 TXT，也可以直接在线编写。
2. 核对解析结果，填写论文来源、方向标签和自己的理解；没有阅读的部分可以留空。
3. 在模板中修改备注，点击“查看发布预览”，再点击“确认发布到仓库”。
4. 发布成功后，论文库从 GitHub 仓库读取已发布内容；有写权限的成员可以点击“编辑笔记”继续更新。

扫描 PDF 暂不支持 OCR，复杂公式、表格和 PDF 插图需要人工校对。未发布的草稿仅保存在当前浏览器。
