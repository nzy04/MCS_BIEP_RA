# 使用指南

## 阅读与检索

在「论文库」搜索标题、作者或关键词，按研究方向筛选。点击作者对应的笔记即可阅读；同一篇论文可保存多份独立笔记。正文中的图片可点击放大。

## 整理研究方向

在主页右键「研究方向」新建；右键具体方向可重命名或删除。上传编辑页的方向也支持右键操作，新建后自动选中。方向可搜索、可多选，管理操作不调用模型。登录且有仓库写权限即可操作。

重命名同步笔记分类与 GitHub 文件夹。删除方向只取消这个分类，论文笔记和图片全部保留，仍可在「全部文献」中找到；没有其他方向的也可在「未分类」查看。删除前会确认。手机可使用方向标题旁的「⋯」新建。

更名或删除后，已打开的旧版本笔记需要刷新再编辑；旧草稿中的失效方向需要重新选择，避免再次生成旧目录。每次管理操作最多同步 250 份笔记，超出时由维护者批量整理；失败时不会提交半套更新。

将论文卡片拖到左侧目标方向，可移动当前方向内这篇论文的全部笔记；拖动作者笔记块则只移动这一份。手机或键盘操作可点击「移动」，选择目标方向并确认。在具体方向中移动会保留其他分类；在「全部文献」中移动会将所选笔记归入目标方向。

移动会同步 GitHub 的方向文件夹、阅读版与目录，正文、图片和署名保持原样。所有有写权限的组员均可整理分类，编辑正文仍只限本人。仅本机笔记的移动保存在本浏览器。

## 上传笔记

添加笔记时可多选方向，审核不会改写手动选择。未选择时，提交后的后台审核会自动归类；编辑和预览阶段不调用模型分类。

1. 使用 GitHub 登录，点击「上传笔记」。发布需要仓库写权限。
2. 选择笔记文件，也可直接「在线写笔记」。
3. 点击「继续整理」，核对正文与论文信息，可修改章节、插入图片、填写图注和编辑表格。
4. 点击「查看发布预览」→「确认发布到仓库」。后台按代码基本校验归档，DeepSeek 仅辅助补充资料、归类和整理格式，在「我的提交」查看结果。简短摘录、初读要点和未填满的栏目都可以贡献，不要求最低字数、个人思考或学术深度。

需要填写标题和实际笔记内容。论文来源、年份和 PDF 下载链接可以留空，后台尝试补全；未找到可靠资料、模型报错或返回异常均不影响发布，之后可自行补充。仅空白、占位文字、链接或附件格式错误、超出容量等基本问题需要修改，页面会用红色列出原因。自动整理只修正基本 Markdown 格式、为无标题段落添加合适的小标题；保留原句、公式、图表和自定义章节，不代写观点或实验数据。

公式支持行内 `$x_t$`、`\(x_t\)` 和独立成段的 `$$...$$`、`\[...\]`，也支持标为 `math` 的代码块。点击编辑器右上角「Markdown」可修改公式源码；阅读、预览、保存和导出均保留 TeX 源码。公式过长时可在公式区域横向滚动。错误语法会保留可读源码，不影响其余内容。

论文库只保存笔记、笔记图片和 PDF 下载链接，不保存 PDF 文件。未填写 PDF 下载链接时，确认提交后会在后台检索补充地址。优先使用论文来源的固定链接规则和公开学术接口，找不到可靠结果时才使用共享搜索兜底。已有链接不会重复检索；无法可靠匹配时保留论文来源，并在审核结果中提示。整理和预览阶段不会触发检索。

| 文件                | 上传方式                                                                                              |
| ------------------- | ----------------------------------------------------------------------------------------------------- |
| Word                | 使用 DOCX，内嵌图片和表格随正文导入。旧版 DOC 需先另存为 DOCX。                                       |
| Markdown + 配图     | 同时选择 Markdown 和全部配套图片，或将笔记与图片打包为 ZIP。配图文件名应互不重复。                    |
| PDF 笔记            | 支持文字型 PDF；导入后核对章节、公式和图表。扫描件需先 OCR。                                          |
| 本地 PDF + 独立笔记 | 笔记放入笔记栏，PDF 放入「本地 PDF 参考」；原文件只在本机处理，不上传。论文地址填入「PDF 下载链接」。 |

选择本地参考 PDF 后，可通过「PDF 选页插图」将指定整页作为笔记图片插入正文；单张框架图可截图后通过「图片」插入。仅保存选入正文的图片。参考模板仅提供提纲，可按论文内容增删。

单个本地导入文件不超过 15 MB，PDF 最多 100 页；发布时单张图片不超过 2 MB，图片合计不超过 6 MB。PDF 下载链接不占用附件容量。

## 修改与导出

打开自己的笔记，点击「编辑笔记」，修改后重新提交。「添加我的笔记」为同一篇论文新建独立笔记。「导出笔记包」下载 Markdown 和附件，导出的 ZIP 可再次导入。

右键作者对应的笔记选择「删除我的笔记」，确认后删除该份笔记及其图片，同篇论文其他成员的笔记保留。网站与后端都只允许上传者删除；删除方向不会删除笔记。误删已发布内容可联系维护者从 GitHub 历史恢复。

编辑中的草稿自动保存在当前浏览器，重新打开时可恢复。正式发布的内容公开可见。点击右上角昵称可修改署名。

## 加入课题组

请维护者在 GitHub 仓库的 Settings → Collaborators → Add people 邀请你的 GitHub 账号。接受邀请后，在网站点击「GitHub 登录」即可维护笔记，无需注册 Cloudflare 或填写 API Key。若先登录后才接受邀请，请退出并重新登录。

网站不设个人或全组每日审核次数上限，同一提交重复点击不会重复调用。模型余额不足或限流时跳过 AI 整理，继续按基本校验发布；仓库写入失败或任务执行中断时保留草稿并按提示处理。服务器审核草稿保留 24 小时、任务记录保留 7 天，已发布笔记保存在 GitHub。重要草稿请导出笔记包备份。
