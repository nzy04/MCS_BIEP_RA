# 使用指南

## 阅读与检索

在「论文库」搜索标题、作者或关键词，按研究方向筛选。点击作者对应的笔记即可阅读；同一篇论文可保存多份独立笔记。正文中的图片可点击放大。

## 按标题收录论文

1. GitHub 登录后，点击导航中的「按标题收录」，输入完整论文标题并检索。
2. 核对候选的标题、作者和年份，选择论文和研究方向，点击「确认收录」。
3. 在「我的提交」查看「收录中 / 已收录」；完成后点击「查看论文」，阅读 PDF 或添加自己的笔记。

检索优先使用 arXiv、Crossref；没有可靠 PDF 结果时才使用共享搜索兜底。PDF 来自公开学术来源。经验证、允许再分发且不超过 4 MB 的 PDF 自动归档到仓库；其他情况保留原站链接或论文信息，并显示原因。论文以独立条目收录，没有笔记时显示「待读」，不会生成虚构的阅读笔记。已收录论文自动复用。

## 上传笔记

研究方向相当于自定义文件夹：可在论文库侧栏或编辑页点击「新建研究方向」，即使暂时没有笔记也会保留。添加笔记时可多选方向；已选方向由你决定，审核不会改写。未选择时，在提交后的后台审核中自动归类，通过后进入相应方向，编辑和预览阶段不调用模型分类。

1. 使用 GitHub 登录，点击「上传笔记」。发布需要仓库写权限。
2. 选择笔记文件，也可直接「在线写笔记」。
3. 点击「继续整理」，核对正文与论文信息，可修改章节、插入图片、填写图注和编辑表格。
4. 点击「查看发布预览」→「确认发布到仓库」。在「我的提交」查看审核进度；通过后自动进入论文库，退回时按反馈修改并重新提交。

| 文件                | 上传方式                                                                           |
| ------------------- | ---------------------------------------------------------------------------------- |
| Word                | 使用 DOCX，内嵌图片和表格随正文导入。旧版 DOC 需先另存为 DOCX。                    |
| Markdown + 配图     | 同时选择 Markdown 和全部配套图片，或将笔记与图片打包为 ZIP。配图文件名应互不重复。 |
| PDF 笔记            | 支持文字型 PDF；导入后核对章节、公式和图表。扫描件需先 OCR。                       |
| 论文 PDF + 独立笔记 | 笔记放入笔记栏，论文 PDF 放入「论文原文」。需要归档原文时勾选「保存 PDF 附件」。   |

附上论文 PDF 后，可通过「PDF 选页插图」将指定整页插入正文；单张框架图可截图后通过「图片」插入。参考模板仅提供提纲，可按论文内容增删。

单个导入文件不超过 15 MB，PDF 最多 100 页；发布时单张图片不超过 2 MB、论文 PDF 不超过 4 MB、附件合计不超过 6 MB。

## 修改与导出

打开自己的笔记，点击「编辑笔记」，修改后重新提交。「添加我的笔记」为同一篇论文新建独立笔记。「导出笔记包」下载 Markdown 和附件，导出的 ZIP 可再次导入。

编辑中的草稿自动保存在当前浏览器，重新打开时可恢复。正式发布的内容公开可见。点击右上角昵称可修改署名。
